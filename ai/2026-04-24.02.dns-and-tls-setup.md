# DNS and TLS Setup

One-time setup to point `adventures.sleepyshortcake.com` at the EC2 instance and provision a TLS certificate.

Uses **DNS-01 challenge** (not HTTP-01) so the Cloudflare proxy (orange cloud) can stay enabled.

---

## 1. Get the EC2 public IP

```bash
aws ssm get-parameter --name /our-adventures/ec2/public-ip --query 'Parameter.Value' --output text
```

---

## 2. Add DNS A record in Cloudflare

1. Go to Cloudflare dashboard → `sleepyshortcake.com` → **DNS**
2. Add a record:
   - Type: `A`
   - Name: `adventures`
   - IPv4 address: the IP from step 1
   - Proxy status: **Proxied** (orange cloud)
3. Save

Verify:

```bash
dig adventures.sleepyshortcake.com +short
```

---

## 3. Create a Cloudflare API token

1. Go to [Cloudflare API Tokens](https://dash.cloudflare.com/profile/api-tokens) → **Create Token**
2. Use the **Edit zone DNS** template
3. Scope it to `sleepyshortcake.com` only
4. **Create token** — copy it, you won't see it again

---

## 4. SSH into the EC2 instance

```bash
ssh -i ~/.ssh/our-adventures-deploy deploy@$(aws ssm get-parameter --name /our-adventures/ec2/public-ip --query 'Parameter.Value' --output text)
```

---

## 5. Provision TLS certificate with Certbot (DNS-01)

Inside the SSH session:

```bash
# Install Certbot and the Cloudflare DNS plugin
sudo dnf install -y certbot python3-certbot-dns-cloudflare

# Store the Cloudflare API token
sudo mkdir -p /etc/letsencrypt
sudo tee /etc/letsencrypt/cloudflare.ini > /dev/null << 'EOF'
dns_cloudflare_api_token = <your-api-token>
EOF
sudo chmod 600 /etc/letsencrypt/cloudflare.ini

# Provision the certificate
sudo certbot certonly \
  --dns-cloudflare \
  --dns-cloudflare-credentials /etc/letsencrypt/cloudflare.ini \
  -d adventures.sleepyshortcake.com

# Configure nginx to use the certificate
sudo certbot install --nginx -d adventures.sleepyshortcake.com
```

Test automatic renewal:

```bash
sudo certbot renew --dry-run
```

---

## Notes

- **IP changes on stop/start.** If the EC2 instance is ever stopped and restarted, it gets a new public IP. Update the Cloudflare A record and rerun Certbot.
- **Certbot auto-renews** via a systemd timer installed automatically — no manual renewal needed under normal operation.
- **Cloudflare token is stored on the instance** at `/etc/letsencrypt/cloudflare.ini` (chmod 600, root only). It is not in SSM or source control.
