# Teardown Plan — Save Money While Unused

**Date:** 2026-10-10

## Context

The app is not being used by Viet or Linh. Infrastructure was costing ~$20–25/month with no active users. Decision: tear everything down to $0. Data (adventure entries) is considered non-critical and will not be backed up. If the app is ever revived, it starts fresh.

## Monthly Cost Breakdown (at time of teardown)

| Resource | Cost |
|---|---|
| RDS t4g.micro (PostgreSQL 18) | ~$13–15/month |
| Elastic IP | ~$3.60/month |
| EC2 t4g.nano | ~$2.50/month |
| RDS storage + 7-day backups | ~$3/month |
| GuardDuty, SSM, CloudTrail | ~$1–2/month |
| **Total** | **~$20–25/month** |

## What to Delete

### Step 1 — Destroy our-adventures ComputeStack

```bash
cd our-adventures/infra
npx cdk destroy ComputeStack
```

Removes: EC2 instance, Elastic IP, EC2 security group, IAM instance role, SSM parameter `/our-adventures/ec2/public-ip`.

### Step 2 — Remove RDS deletion protection

In `shared-aws-infra/lib/database-stack.ts`, change:
```ts
deletionProtection: true,
```
to:
```ts
deletionProtection: false,
```

Deploy the change:
```bash
cd shared-aws-infra
npm run build && npx cdk deploy DatabaseStack
```

### Step 3 — Destroy shared-aws-infra (all stacks)

```bash
cd shared-aws-infra
npx cdk destroy --all
```

Destroys (in reverse dependency order): SecurityStack, BillingStack, DatabaseStack, NetworkStack.

Note: CloudTrail S3 bucket has `RemovalPolicy.RETAIN` — it will remain in the AWS account after stack deletion. Delete it manually via the console if desired.

### Step 4 — Clean up SSM parameters (manual)

Any SecureString parameters not managed by CDK (e.g. app secrets stored manually):
- `/our-adventures/db/password`
- `/our-adventures/auth/google-client-id`
- `/our-adventures/auth/google-client-secret`
- `/our-adventures/auth/secret`
- `/our-adventures/cloudflare/dns-api-token`
- `/our-adventures/cloudflare/zone-id`

Delete via AWS Console → Systems Manager → Parameter Store, or:
```bash
aws ssm delete-parameters --names \
  /our-adventures/db/password \
  /our-adventures/auth/google-client-id \
  /our-adventures/auth/google-client-secret \
  /our-adventures/auth/secret \
  /our-adventures/cloudflare/dns-api-token \
  /our-adventures/cloudflare/zone-id
```

## Reviving the App Later

To bring it back:
1. Manually re-create SSM SecureString parameters (Step 4 in reverse)
2. Run `deploy-infra.yml` (manual workflow dispatch) to recreate shared-aws-infra
3. Run `deploy-infra.yml` for our-adventures ComputeStack
4. Push to main to trigger `deploy-app.yml`
